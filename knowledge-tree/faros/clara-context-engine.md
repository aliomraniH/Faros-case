The named (branded "Clara") product that feeds AI coding agents a repo's tribal knowledge so they
produce review-ready code. "Context in. Rework out." Four pillars on the page: historical replay,
agentic PR delivery (Jira ticket enhancement → spec → code with Claude/Codex/Copilot/Cursor),
human-in-the-loop review, continuous learning. The product surface reads as shipped; deeper
sub-claims (historical replay as a finished feature, write-back of failure lessons) are proposed
separately with honesty flags. Human-in-the-loop framing corroborates `principle:empower-not-police`.
